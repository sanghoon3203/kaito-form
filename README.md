# kaito-form

株式会社カイトー商会の図面・案件の受付フォームです。PHP で動きます。

## 全体の流れ

1. 利用者が `public/index.html` のフォームに会社名・案件情報を入力し、図面(PDF・JWW)を添付します。
2. `public/api.php` が Cloudflare Turnstile でボットでないことを確かめてから、Google Apps Script(`Code.gs`)に受付を依頼します。
3. 図面は分割して Google ドライブに保存されます。ファイルの中身は `api.php` が Google へ中継します。
4. `Code.gs` が受付一覧のシートと、案件管理表の「案件基本情報」に1行ずつ追加し、通知メールを送ります。

## 必要なもの

- PHP 7.4 以上(curl・mbstring 拡張)
- Apache の場合は `public/.htaccess` が効く設定(`AllowOverride All`)

## 設置

1. `public/` の中身を公開フォルダに置きます。
2. `.env.example` を写して `.env` を作り、値を入れます。`.env` は公開フォルダの一つ上に置きます。置けないサーバーでは `public/` に置いても動きますが、その場合は `.htaccess` で外から読めないようになっていることを確かめてください。
3. Cloudflare Turnstile のウィジェット設定で、ホスト名に設置先のドメインを追加します。

## Apps Script(Code.gs)

Google Apps Script のプロジェクトに `Code.gs` を貼り、ウェブアプリとしてデプロイします。Drive API(高度なサービス)を有効にしてください。Script Properties に次を設定します。

| キー | 内容 |
|---|---|
| `SHARED_SECRET` | `.env` の `SHARED_SECRET` と同じ値 |
| `ROOT_FOLDER_ID` | 図面を保存するドライブのフォルダ ID |
| `SHEET_ID` | 受付一覧のスプレッドシート ID |
| `NOTIFY_EMAIL` | 通知メールの宛先 |
| `CASE_SHEET_ID` | 案件管理表のスプレッドシート ID。未設定なら案件管理表には書き込みません |
| `CASE_SHEET_NAME` | 書き込むシート名。省略すると「案件基本情報」 |

案件管理表を共有ドライブへ移したときは、`CASE_SHEET_ID` を新しい ID に変えるだけで切り替わります。Apps Script を動かすアカウントに、そのファイルの編集権限が必要です。

## 案件基本情報への書き込み

フォームの入力は次の列に入ります。それ以外の列(案件番号・ステータス・金額・入金など)は空欄のままにし、社内で入力します。

| 列 | 項目 | フォームの入力 |
|---|---|---|
| C | 顧客名 | 会社名 |
| D | 顧客支店名 | 支店名 |
| G | 案件名 | 案件名 |
| H | 案件住所 | 案件住所 |
| K | 床下暖房種別 | 放熱器・AC・ﾌｧﾝｺﾝﾍﾞｸﾀｰ・未定 |
| L | 備考 | 受付日・担当者・メールアドレス・図面フォルダのリンク・備考 |
| P | 着工予定日 | 着工予定日 |
| Q | 完工予定日 | 工事完了予定日 |

E 列(顧客住所)・F 列(顧客電話番号)・W 列(未回収残高)のような自動の列には値を書かず、直前の行に数式があれば同じ数式を入れます。顧客名のプルダウンにない会社名などで入力規則に拒否された値は、その列を空欄にして備考に書き残します。

## 動作確認

```
php tests/smoke.php
```

`api.php` と偽の Apps Script をローカルで起動し、入力チェック・Turnstile の確認・受付の流れを確かめます。Turnstile は Cloudflare のテスト用キーを使うので、インターネットへの接続が必要です。Google ドライブへの実際のアップロードは確かめません。
